# Homebrew tap for Zinc

```sh
brew install frulko/zinc/zinc    # the zinc CLI, latest release
brew upgrade zinc                # a new release
```

`Formula/zinc.rb` is written by the release workflow of [Frulko/zinc](https://github.com/Frulko/zinc)
(`next/tools/homebrew-formula`) on each stable release: do not edit it by hand.
